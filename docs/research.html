Software

CMAQ-hyd

CMAQ-hyd is an augmented version of the Community Multiscale Air Quality Model (CMAQ v5.3.2) that computes semi-normalized first- and second-order partial derivatives of output concentrations with respect to selected input emissions, using hyperdual numbers to eliminate higher-than-second-order terms in the Taylor expansion.

Repository · doi:10.5281/zenodo.17362476 · MIT license · Released 2025-10-15

pyAERMOD

A Python wrapper for AERMOD, EPA’s regulatory steady-state plume dispersion model.

In development

GEOS-Chem-hyd

Hyperdual-step, source-oriented sensitivity analysis in GEOS-Chem, including a hyperdual treatment of the HEMCO emissions component. Released publicly as GEOS-Chem-hyd v0 in October 2025 and described in Akinjole and Capps (2025).

doi:10.5281/zenodo.16575028 · Released 2025-10-30
